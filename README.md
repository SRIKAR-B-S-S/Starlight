# Starlight

A quick zero-distraction micro-journaling app for all your 3am ideas with a spooky theme.

## Features
It comes with all the essential features such as a timestamp of last edited date and time, saving the notes into your local storage(works even offline!), Ctrl+S hotkey to take care of the reflexes of many people such as me who use the save hotkey after completing every line and also the users can simply press 'S' to focus on the textarea without the need of their mouse and also use the Esc key to remove focus from the textarea.

## Spooky Elements
Starlight comes with multiple spooky elements such as a pumpkin icon using which we can toggle the background horror sound. A spider mouse pointer instead of your normal cursor. A quick blur feature where the user can press and hold the Esc key to hide his notes and ideas from the passing-by ghosts! There are also some horrorful messages whcih will be displayed to the users randomly at random intervals of time.. The title of Starlight tab will also change is something eerie if the user is not on the Starlight tab. I've also implemented the feature of switching themes, I've named them *Shadow* and *Dark* according to the colours of the themes.

## How I made it
I used HTML, CSS and JS for developing Starlight. The website's frontend is based on HTML and CSS whereas the backend is developed with JS for things such as display random horror messages at random intervals of time, displaying the away from Starlight title, hotkeys and especially the timestamps

## Where I struggled and what I enjoyed
I struggled to implement the feature where I thought of displaying only the time in the timestamp if the note was last editedon the same day whereas it should display the date and time in the timestamp if the the notes was edited on the previous day. Such as if I have last edited my notes this morning then it should show me only the time and when I check it the next day it should display the time along with the date. Though I really enjoyed brainstorming for adding the spooky features, especially while writing the horrorful messsages!
